## NDHU IM25 Graduation Project

VR-based vocational training system that addresses the limitations of
physical training (limited practice opportunities) and web-based training
(unsuitable for conversational scenarios).

### Repositories

| Repo | Description |
|------|-------------|
| [IM25_HDRP](https://github.com/Love-MrHou/IM25_HDRP) | Main VR training system built with Unity HDRP |
| [IM25_final](https://github.com/Love-MrHou/IM25_final) | Final release version |

### Tech Stack

Unity (HDRP) / C# / VR

### Team

National Dong Hwa University, Information Management, Class of 2025
